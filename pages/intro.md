# sim — Simulation, ROS2 & Robot Learning

Simulation/digital-twin engineering: ROS2, Gazebo, MuJoCo, Isaac Lab, RL, and VR/AR teleoperation. Scope is
deliberately narrow — simulation fidelity + sim-to-real/RL + middleware integration + VR/AR, not generalist
robotics — matching what target roles (NVIDIA, Oversonic, Xaba, Qualcomm, Accenture Physical AI, and remote
roles on Alignerr/Mindrift/Micro1/Toptal) actually ask for.

Each chapter in the sidebar is both a concept write-up **and** the working code/experiments for that concept —
read it like a book, or jump straight to the linked source on [GitHub](https://github.com/Kooroshoo/sim).
